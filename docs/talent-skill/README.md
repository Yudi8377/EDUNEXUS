# EDUNEXUS Talent & Skill

Foundation implementation aligned with the Talent & Skill Platform blueprint.

## Scope
- Character development
- Talent & interest discovery
- Soft skills
- Hard skills across non-IT and IT domains
- Life skills
- Goal-based development pathways
- Skill Passport and evidence
- Mentor/parent/school/provider collaboration
- AI coaching with safety guardrails
- Live-session performance analytics based only on observable, task-relevant indicators

## Safety invariant
EDUNEXUS must not infer or diagnose emotion, mental health, personality, or character from face, voice, movement, or biometric signals. Live analytics are evidence for learning activities and remain subject to human review.
