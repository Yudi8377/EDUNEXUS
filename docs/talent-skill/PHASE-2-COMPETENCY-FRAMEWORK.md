# Phase 2 — Competency Framework v1

## Design rule
Competency is measurable capability, not a personality label.

## Domains
1. Character — habits and responsible behavior observed in context.
2. Talent & Interest — preferences, exploration signals and sustained engagement.
3. Soft Skill — communication, collaboration, leadership, critical thinking, adaptability.
4. Hard Skill — domain-specific technical capability.
5. Life Skill — practical independence, financial literacy, safety and decision making.

## Competency record
Each competency has: id, domain, level, observable indicators, learning activities, evidence types, assessment rubric, age suitability, safety classification and reviewer role.

## Levels
Explore → Foundation → Developing → Proficient → Advanced → Applied/Portfolio.

## Evidence principle
AI may assist evidence extraction, but an AI observation is not equivalent to a final competency judgment. Mentor/teacher review remains authoritative for high-impact decisions.

## Age-aware design
For minors, tasks and language are age-appropriate. Sensitive inference is prohibited. Parent/guardian controls apply to governed data and live-session analysis.
