# AI Live Performance & Development Governance

## Allowed observations
- speech clarity and pace
- filler-word counts
- presentation structure
- response timing
- turn-taking
- participation in a defined activity
- task adherence
- observable presentation/posture cues when explicitly relevant to the task
- transcript relevance and completeness

## Prohibited inference
The system must not infer or diagnose emotion, mental health, personality, intelligence, character quality, protected traits, or other sensitive attributes from face, voice, movement or biometric signals.

## Processing defaults
- post-session analysis is preferred for minors
- raw video/audio retention is off by default
- explicit consent is required before governed capture/analysis
- portfolio publication requires separate explicit permission
- human review is required before consequential development decisions
- every analysis result carries purpose, model/version, consent context and review state

## Review flow
Capture → Consent Check → AI Observation → AI Analysis → Mentor Review → Development Feedback → Skill Evidence → Skill Passport.

## Integration
Zoom, Google Meet, Microsoft Teams and native WebRTC are adapters. The competency/evidence model must remain provider-neutral.
